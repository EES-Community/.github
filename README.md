# Engineering Equation Solver Community and Open Source Projects

The official GitHub home for **Engineering Equation Solver (EES)** and related open-source ecosystem tools. 

EES is a robust, general equation-solving program capable of solving thousands of coupled non-linear algebraic and differential equations. We are building an open-source ecosystem here to help engineers, researchers, and students integrate EES into modern technical workflows.

## Contributing

We actively welcome contributions from the engineering and academic communities! Whether you are submitting a bug fix for one of our API wrappers, sharing a custom thermodynamic model, or improving our documentation, your input helps modernize the EES ecosystem for everyone. 

Please check the `CONTRIBUTING.md` file in individual repositories for specific guidelines on how to submit pull requests.
